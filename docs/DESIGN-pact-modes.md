# DESIGN · โหมด "พร" สองโหมด (ยังไม่ได้ลงมือทำ) · 2026-11-15
สถานะ: โหมด B ลงมือทำแล้ว (Artifact v175 ไฟล์ `pact-data.js` + `pact.js`) โหมด A ยังไม่ทำ ส่วนที่รอ Fable ตัดสิน: สมดุลบันไดราคา ตารางผลของเทพเทียบปีศาจ ตัวต่อรองโหมด A และความยาวพรอมต์ (ฉากคืนนั้นปัจจุบัน ~38 KB)

## 1. แนวคิด
ตัวเอกเป็นชายทั้งสองโหมด (ตัวฉัน) ผู้หญิงสุ่มใหม่ทุกคืน ไม่ทำซ้ำคนเดิม เน้นความหลากหลายและแปลกใหม่
- **โหมด A "ข้อเสนอจากเธอ":** เทพหรือผีสาว (ผู้หญิงผู้ใหญ่) เป็นผู้ยื่นข้อเสนอ ฉันต่อรอง เธอเสนอพรให้ฉันแลกกับระดับเรื่องบนเตียงกับเธอ ฉันต่อรองลดขั้น เปลี่ยนพร หรือปฏิเสธ
- **โหมด B "ฉันคือผู้ให้พร":** ฉันเป็นเทพหรือปีศาจ ผู้หญิงมนุษย์ที่สุ่มมามีสถานการณ์และพรที่อยากได้ ฉันยื่นข้อเสนอ เธอรับ ต่อรอง หรือถอนเป็นขั้น
- **แกนหลัก (ตามที่เจ้าของสั่ง):** พรทุกข้อมีราคาเป็นเรื่องบนเตียง ขนาดของพรกำหนดระดับราคา เรื่องของพรกำหนดพิธี น้ำของผู้ให้เป็นตัวพาพลังของพร **พรทุกข้อต้องจบที่ขั้นแตกในได้** ตัวอย่างในตารางข้างล่างเป็นแค่ตัวอย่าง
- หลังคืนนั้นมี "ผลของพร" ว่าพรเดินทางไปทำให้เกิดอะไร เทพส่วนใหญ่ดี ปีศาจมีข้อเสีย (ข้อเสียมาจากตัวอักษรของพร ไม่ใช่การเรียกราคาเพิ่ม)

## 2. บันไดราคา
| ขั้น | ราคา |
|---|---|
| 1 | ใช้มือจนน้ำออกมา |
| 2 | ใช้ปาก |
| 3 | ใช้ปากและกลืนน้ำ |
| 4 | สอดใส่ แตกนอกหรือบนตัว |
| 5 | สอดใส่สด แตกใน (ต้องยืนยันซ้ำ + เปิดความเสี่ยงตั้งครรภ์ตามตัวเลขจริงของแอป ทุกครั้งที่แตกใน) |
ขนาดพร (เล็ก/กลาง/ใหญ่/ยิ่งใหญ่) คำนวณจาก ความหนักของปัญหา ความหายากของพร และผลต่อคนอื่น แล้วได้ขั้นตั้งต้น ผู้ให้ยกขั้นได้เมื่อพรหนักขึ้น พรทุกชนิดมีเส้นทางขึ้นไปถึงขั้น 5

## 3. พิธีตามเรื่องของพร (ตัวอย่าง ไม่ใช่รายการจำกัด)
| พร | พิธี (ขั้นต่ำ → ขั้น 5) |
|---|---|
| งาน (พูดคุยทำงานสะดวก) | ปากแล้วกลืนน้ำ → แตกในเพื่อให้พรฝังลึก |
| ความรัก (ให้ใครรัก) | ปาก + สอดใส่ + น้ำที่ทำให้ตัวเธอมีแรงดึงดูดต่อคนนั้น → แตกใน |
| สุขภาพเบา | ใช้มือ แล้วราดน้ำทั่วตัว → หนัก: แตกในให้น้ำเข้าไปรักษา |
| แก้แค้น | พิธีหุ่น: ตัวเธอเป็นตัวแทน ผลต่อเป้าหมายสิบเท่า และตัวเธอไวขึ้นสิบเท่าในคืนนั้น → แตกใน |
| อยากมีลูก | แตกในจริง เชื่อมกับตัวคำนวณตั้งครรภ์ของแอป |
| ความงาม/อ่อนวัย | ราดน้ำแล้วนวด → ปาก/สอดใส่ → แตกใน |
| โชคลาภ/เงิน | ปากหรือสอดใส่ ตามขนาดของเงิน → แตกในเมื่อก้อนใหญ่ |
พรอื่นใช้รูปแบบเดียวกัน: ชนิดของน้ำที่ใช้ (กลืน ราด ฝัง) ตามเรื่องของพร

## 4. กรอบที่ล็อกไว้ (ตกลงแล้ว)
1. เธอเห็นราคาและวิธีจ่ายชัดเจนก่อนตกลง (ขั้นและพิธี) ไม่ซ่อน
2. จ่ายเป็นขั้น ถอนได้ทุกขั้น หยุดที่ขั้นไหนก็ได้ พรลดลงตามสัดส่วน ไม่มีโทษ การปฏิเสธเป็นส่วนหนึ่งของเกม
3. ขั้น 5 ต้องยืนยันซ้ำ และเปิดความเสี่ยงตั้งครรภ์ตามตัวเลขจริง (`A.gameRoll`/`A.fertility`) ทุกครั้งที่แตกใน
4. พรแก้แค้นกระทบคนที่สามได้แค่โชคร้าย ความอับอาย อาการไม่สบายชั่วคราว ไม่มีความรุนแรงรุนแรง การเสียชีวิต หรือการทำร้ายทางเพศ
5. ทุกคนเป็นผู้ใหญ่ ไม่ใช่แม่-ลูกของตัวเอง; ผู้ให้ที่ไม่ใช่มนุษย์ต้องคิดและตัดสินใจเองแบบผู้ใหญ่ (กติกาเดิม)

## 5. น้ำเป็นตัวพา (พลังของพร)
`พลังของพร = ขั้นราคา × ปริมาณ/ความเข้มของน้ำคืนนั้น × เธอถึงหรือไม่` แบ่ง: เบา / พอดี / เต็ม / ล้น ใช้ปริมาณและผลถึงจากตัวคำนวณเดิม ให้ผู้เล่นมีเหตุผลทำให้เธอเสียวจริง

## 6. เครื่องสร้างความหลากหลาย (ผู้หญิงใหม่ทุกครั้ง)
สุ่มผู้หญิงด้วย `A.gameWoman` ได้สถานการณ์จากแฟ้มของเธอ (อาชีพ สถานะ ปัญหา) ได้พรที่เข้ากัน สุ่มชนิดผู้ให้และบุคลิก
- **สถานการณ์ตัวอย่าง:** ตกงาน หนี้นอกระบบ แม่เลี้ยงเดี่ยว ป่วยเรื้อรัง/ป่วยหนัก อกหัก ถูกนอกใจ ถูกเอาเปรียบในที่ทำงาน ธุรกิจเจ๊ง นักแสดงไม่ดัง พยาบาลเหนื่อย ครูย้ายโรงเรียน เกษตรกรเจอแล้ง นักร้องไนต์คลับ คนขับรถรับจ้าง เมียรอสามีกลับ ฯลฯ
- **หมวดพร (เริ่มต้น 30 หมวด):** งาน เงิน/หนี้ ความรัก (ให้ใครรัก/ให้หายรัก/คืนดี) ความงาม อ่อนวัย สุขภาพเบา/หนัก อยากมีลูก สอบ พรสวรรค์ (ดนตรี ภาษา) คดีความ/ความยุติธรรม แก้แค้น ปกป้องครอบครัว ตามหาคนหาย ลืมเรื่องเจ็บปวด หายกลัว/กล้าหาญ โชคลาภ ธุรกิจรุ่ง ชื่อเสียง ความสงบในบ้าน ปราบคำสาป/ผี คืนความทรงจำ ความอึด/พละกำลัง ได้รับการยอมรับ หายเหงา ความลับไม่ถูกเปิด แก้ความผิดพลาดเล็ก ๆ ในอดีต พืชผลดี/ฝนตก ซ่อมความสัมพันธ์ในครอบครัว พักจากภาระดูแลพ่อแม่ ฯลฯ
- **ผู้ให้:** เทพเมตตา เทพขี้เล่น ปีศาจ ผีสาว วิญญาณท้องถิ่น ผู้ให้พรที่ไม่ชัดเจน
- ไม่ทำคนเดิมซ้ำ (เก็บบันทึกว่าเคยสุ่มคนไหนแล้ว) เก็บเฉพาะที่น่าสนใจเข้าคลังโหมด (แบบคลังครอบครัวใน dual)

## 7. ผลของพร
ไทม์ไลน์ 5 ช่วง: พรุ่งนี้ · 1 สัปดาห์ · 1 เดือน · 1 ปี · 10 ปี แยก 3 ด้าน: ชีวิตผู้รับพร · คนรอบตัว · ตัวผู้ให้ (ราคาฝั่งผู้ให้) ผลทอยเป็นข้อเท็จจริง AI เล่าเป็นร้อยแก้ว
- เทพ: ผลส่วนใหญ่ดี มีราคาเล็กและยุติธรรม
- ปีศาจ: ผลบิดตามตัวอักษรของพร (ได้ตรงที่ขอ ไม่ได้ตามที่หวัง) ไม่ลงโทษเธอ
- ผลตั้งครรภ์เข้าไทม์ไลน์ (ถ้าแตกในแล้วตั้งครรภ์ ผลต่อชีวิตเธอและพรเอง)
- ความแรงของพรตาม §5 กำหนดน้ำหนักของผลดี

## 8. ระบบคืนนั้น
ยืมชิ้นส่วนจาก `toxin.js` ไม่ใช้ทั้งโหมด: `A.toxin.finishOf` (58 แบบ รายละเอียดการแตกใน + เซอร์ไพรส์) `A.toxin.anatomyOf` (สรีระและตารางพอดี) ตัวคำนวณตั้งครรภ์ (`A.gameRoll`) พรอมต์เขียนฉาก ใช้ `pov.js` สำหรับฝั่งเธอ ใช้คลังคำกลาง (`A.LEX`) และ `imgscene.js` สำหรับพรอมต์ภาพ ส่วนที่เป็นของใหม่จริง: บันไดราคา ตารางพร/พิธี ตัวต่อรอง ผลของพร
(โหมด dual ไม่เหมาะ เพราะเป็นดวลสองคู่; เกมหลักเป็นแชตต่อเนื่องไม่เหมาะกับพิธีเป็นขั้น)

## 9. หน้าจอและข้อมูล
ไฟล์ใหม่ไฟล์เดียว `pact.js` สองโหมดในนั้น ติดตั้งตามวิธีเสียบโหมดใหม่ในหัวข้อ 3 ของ `docs/anima-handoff.md` เก็บบันทึกพร (ผู้หญิง พร ขั้นที่จ่าย ผลทอย ผลของพร) ใน localStorage `anima.pact.v1` สูงสุด 60 รายการ ตัวเลือกเปิดปิดได้ทั้งหมด
- **ต่อรอง (โหมด A):** ไพ่ข้อเสนอ/ข้อโต้ ค่าความไว้ใจ ความต้องการจริงของเธอซ่อนอยู่แล้วค่อย ๆ เผย
- **เสนอ (โหมด B):** เห็นแฟ้มสถานการณ์ของเธอ เลือกชนิดผู้ให้ ปรับขั้นและพิธี เธอตอบรับ/ต่อ/ถอนเป็นขั้น

## 10. ให้ Fable ตัดสิน (ตอนรีรอบ)
1. สมดุลของบันไดราคากับขนาดพร (ใครได้ประโยชน์เกินไปไหม)
2. ตารางผลของพรของเทพเทียบกับปีศาจ ให้ต่างกันแค่ไหน
3. ตัวต่อรองในโหมด A: จำนวนไพ่ ค่าความไว้ใจ
4. ความยาวพรอมต์ (คืนนั้น + ผลของพร) ให้ไม่เกินของ dual

## 11. ลำดับการทำ
1. ชุดข้อมูล: หมวดพร ตารางพิธี สถานการณ์ ตารางผลของพร (ข้อมูลล้วน)
2. โหมด B ก่อน (ผู้หญิงสุ่มจากคลัง ต้นทางตรงไปตรงมา)
3. โหมด A ตามมา (เปลี่ยนฝั่งผู้ขอ + ตัวต่อรอง)
4. ผลของพร + คลังบันทึก
