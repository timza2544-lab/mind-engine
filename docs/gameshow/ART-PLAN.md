# แผนงานภาพ/คลิปของเกมโชว์ลับ (ฉากหลัก)

เป้าหมาย: ทำคลิปพิกเซลให้ครบก่อนในโฟลเดอร์แยก ตรวจในคลังคลิปได้ครบทุกใบ แล้วค่อยนำที่ผ่านแล้วเข้าเกม
อยู่ที่ `docs/gameshow/art/` — `art.js` (เอนจิน), `gen.js` (สร้างคลิปทั้งหมด), `gifs/` (ผลลัพธ์), `manifest.json`, `index.html` (คลังตรวจ)

## ข้อกำหนดของภาพ
- 128x80 พิกเซล 24 สี ขยาย 5 เท่า (640x400) วนลูป 6 เฟรม
- ผู้ใหญ่เท่านั้น ร่างเป็นเงาพร้อมแรเงา ไม่มีรายละเอียดอวัยวะเพศ ผ้าห่มคลุมจุดต่อ
- ชื่อไฟล์: `{pos}-{rhythm}-{outfit}.gif`, `climax-{pos}.gif`, `after-{kind}.gif`

## ชุดคลิป (เฟส 1 ทำแล้ว: 73 ใบ)
| ชุด | จำนวน | รายละเอียด |
|---|---|---|
| ท่า x จังหวะ x สภาพชุด | 63 | 7 ท่า (คร่อมหันหน้า, หันหลัง, นั่งยอง, โน้มตัวกระซิบ, เอนหลังยันต้นขา, นั่งตัก, หมุนตัวครึ่งรอบ) x 3 จังหวะ x 3 ชุด |
| จุดสูงสุด | 7 | ทุกท่า สั่น หัวใจ ประกาย |
| หลังจบ | 3 | กอด, หัวเราะ, ห่มผ้า |

## เฟสถัดไป (รอตรวจเฟส 1)
2. สีหน้า/ความร้อนแยกเป็นชุด (เฟสนี้ผูกกับมิเตอร์อยู่แล้ว ตรวจว่าตรงไหม)
3. ช่วงเริ่ม: ขึ้นคร่อม, ถามอนุญาต, ถอดชุดทีละชิ้น (คลิปเปลี่ยนสถานะ)
4. มุมกล้องอื่น: เหนือไหล่, ใกล้หน้า, มุมมองจากข้างบน
5. ฉากเกมโชว์: เวที, ห้องแยก, พิธีกร, ผู้ชม

## วิธีตรวจ
เปิดคลังคลิป กรองตามท่า/จังหวะ/ชุด กด ใช้ได้ / ต้องแก้ (เขียนโน้ต) / ตัดทิ้ง แล้ว "คัดลอกสรุป" ส่งกลับมา ผมแก้ตามโน้ตแล้วสร้างใหม่ด้วย `node gen.js`

## การนำเข้าเกม (หลังตรวจผ่าน)
เกมอ่าน `manifest.json` เฉพาะใบที่ผ่าน แล้วเลือกคลิปตาม (ท่า, จังหวะ, ชุด) ที่ผู้เล่นเลือกอยู่ แทนการวาดสดในหน้า
