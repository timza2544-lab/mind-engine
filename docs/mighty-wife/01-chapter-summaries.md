# ไมตี้ไวฟ์ (มนุษย์เมียจอมพลัง) — สรุปเนื้อเรื่องรายตอน

สรุปด้วยคำของฉันเอง จากฉบับแปลไทยที่ผู้ใช้ส่งมา ใช้เป็นเอกสารอ้างอิงสำหรับสร้างโหมดเล่าเรื่องใน Anima
ไม่มีบทพูดคัดลอกจากต้นฉบับ ตัวละครทุกคนที่ใช้ต้องเป็นผู้ใหญ่ ฉากทุกฉากต้องเป็นความเต็มใจ มีคำหยุด

**ตอนที่ไม่ใช้:** ตอน 11 และ 16 (ตัวชายสำคัญเป็นเด็ก) ไม่อ่านต่อ ไม่สรุป ไม่ใช้ในงานใดทั้งสิ้น
**ส่วนที่ตัดทิ้งในตอนอื่น:** ฉากที่เธอปฏิเสธ/ร้องห้ามแล้วถูกทำต่อ ฉากรุม ฉากถ่ายคลิปโดยไม่ยินยอม และภาพที่เกี่ยวกับความเป็นเด็ก ไม่สรุปรายละเอียด

## โลกและกฎ (รวม)
- **แมรี่ อายุ 28** แม่บ้านที่ทักทายสามีอบอุ่น แต่เรื่องบนเตียงของคู่กำลังวิกฤติ
- **อีกชีวิต:** ฮีโร่ "ไมตี้ไวฟ์" (ชุดมีโลโก้ W) ออกปราบปีศาจเมื่อมีข่าวด่วน สามีไม่รู้
- **กฎพลัง:** พลังหมดแล้วต้องเติมด้วย "พลังน้ำรัก" ของสามี (แหล่งจริงมีแหล่งเดียว ของคนอื่นเติมเกือบไม่ได้ผลหรือให้แค่ช่วงสั้น)
- **เสียงที่สามคั่นเรื่อง:** ผู้ประกาศข่าว ช่องความเห็นสด ผู้ชมทั้งเมือง หุ่นยนต์ผู้ช่วย "ด็อก"
- **ตัวร้าย:** ราชินีปีศาจกับสมุนปรสิต ฝั่งตัวร้ายกฎต่างกัน (น้ำของใครก็เป็นพลังได้)

## ตอน 1 (ไม่มีเลขตอนในไฟล์)
เปิดด้วยครอบครัวธรรมดา ตัดเข้าข่าวด่วนทันที แมรี่แปลงร่างไปสู้ พลังไม่พอ ถูกจับ จบหน้าด้วยจุดที่เธอเสียเปรียบ
ใช้ได้: ชีวิตสองชั้น, พลังผูกกับเรื่องบนเตียงจึงเป็นเดิมพันของเรื่อง, คอมเมดี้สลับความตึง, เล่นคำสุภาพแทนคำตรง
ไม่ใช้: ช่วงถูกจับและถูกบังคับ

## ตอน 2
ข่าวรายงานว่าไมตี้ไวฟ์พ่ายแพ้ แมรี่บอกตัวเองว่า "แกล้งยอม" ลูกน้องสามีพาสามีเมามาส่งที่บ้าน สามีหลับบนโซฟา หนุ่มซื่อได้ยินเธอพึมพำ แล้วสารภาพว่าชอบเธอ ข่าวปีศาจเข้ามาพอดี เธอตัดสินใจเองว่าต้องเร็ว ฉากเกิดข้างสามีที่หลับ ทีวียังรายงานคั่น จบด้วยสามีตื่นอยู่และแอบดูเธอในข่าว
เทคนิค: ทำต่อหน้าแต่ไม่ให้รู้ / นาฬิกาจากโลกนอก / ใจกับร่างขัดกัน / เสียงที่สามเป็นมุก / จบด้วยประชด

## ตอน 3
สามีไม่แตะเธอสามสัปดาห์ เธอประชด คืนนั้นเธอได้พลังเต็มแต่คุมไม่อยู่ พุ่งไปตกเกาะร้างที่มีชายหนุ่มอยู่คนเดียว เก้าวันด้วยกันเล่าเป็นภาพตัดต่อ ต่อแพ ทะเลาะ ดูดาว เธอเป็นฝ่ายเริ่มเพราะเขาไม่เคยมีประสบการณ์ เธอ "สอน" ช้า ๆ ท่าทีเขาเปลี่ยนจากสุภาพเป็นนำ เธอคิดถึงสามีน้อยลง ปมตลก: ทำกันหลายสิบครั้งพลังไม่เพิ่ม แต่สามีทำครั้งเดียวเต็ม
เทคนิค: ภาพตัดต่อวัน / ไล่ท่าทีเป็นขั้น (ลังเล→ตั้งใจสอน→ติดใจ→เขานำ) / ผู้ชายอีกคนมีเรื่องของตัวเอง / กฎพลังหักมุม
ไม่ใช้: ช่วงท้ายที่เธอขอให้หยุดแล้วไม่หยุด

## ตอน 4
งานถ่ายแบบไมตี้ไวฟ์ ผู้จัดเข้าใจผิดว่าแมรี่เป็นนางแบบ เธอรับบทเพื่อล่อปีศาจ งานเปลี่ยนเป็นประมูลสิทธิ์สัมผัส คนยกมือคือสามีเธอเอง เขาขึ้นเวทีแล้วทำไม่ได้เพราะซื่อสัตย์ต่อเมีย เธอทั้งโกรธและซาบซึ้ง
เทคนิค: เข้าใจผิดเรื่องตัวตน / ราคาเป็นกลไกไต่ระดับ / สามีมีหัวใจ ไม่ได้ไม่แตะเพราะเลว
ไม่ใช้: ช่วงท้ายที่ฝูงชนรุมโดยเธอร้องห้าม

## ตอน 5
หน้าแนะนำตัวละครแบบหนังสือ เธอหนีไปสถานีอวกาศของด็อก แปลงร่างคืนไม่ได้ เส้นตายคือสามีกลับ 9 โมง ด็อกใช้ "คาราเต้คุง" ไซบอร์กชายบริสุทธิ์ช่วยปลดล็อกชุด เธอเป็นฝ่ายตัดสินใจช่วยเขา มุกวิทยาศาสตร์เรื่องวันตกไข่ ปลอดภัยแต่ผู้อ่านรู้ว่าพลาดได้ จบที่เธอขอเพิ่มอีก กลับไม่ทัน 9 โมง
เทคนิค: เส้นตายที่ผู้อ่านนับตาม / คำอธิบายวิทยาศาสตร์เป็นมุก / ความเสี่ยงแบบมีเงื่อนไข / ท่าทีพลิกกลางตอน
ไม่ใช้: ช่วงเปิดที่เธอถูกตรึงและปฏิเสธ

## ตอน 6
ทีวีถกว่าไมตี้ไวฟ์เป็นฮีโร่จริงหรือนางแบบ สามีด่าไมตี้ไวฟ์ทั้งที่แอบชอบ เธอรู้ที่มาของปัญหาพลัง เธอสวมชุดให้สามี เขาบอกว่าสนใจเธอไม่ใช่ไมตี้ไวฟ์ ทั้งคู่เล่นสวมบท เซ็กส์ที่ยิ้ม แซวกัน พลังเต็มจริง ตัดไปฝั่งปีศาจ
เทคนิค: สามีขัดแย้งในตัว / เซ็กส์อบอุ่นเต็มใจทั้งคู่ / วงจรปิดจากหลายตอนที่ไปหาพลังที่อื่น
ไม่ใช้: ฉากรุมราชินีปีศาจท้ายตอน

## ตอน 7 (ตัวเอกคือราชินีปีศาจ)
แมรี่ชนะราชินีจนตกหาด ราชินีไม่มีใครจำได้ ถูกหนุ่มชวนนั่งพัก อยากกินน้ำเพื่อเอาพลังคืน ตกลงให้ไลฟ์ แต่พอรู้ว่าไลฟ์ทั่วโลก ขอหยุดแล้วไม่หยุด จบด้วยราชินีโทษแมรี่และสาบานฆ่า ช่องความเห็นสดเป็นมุก
เทคนิค: กฎโลกสะท้อนกัน / ช่องความเห็นสด / จบด้วยตัวร้ายสาบานแค้น
ไม่ใช้: ฉากหลักที่ขอหยุดแล้วถูกรุมไลฟ์

## ตอน 8
เปิดและปิดด้วยเด็กน้อยข้างทางทักไมตี้ไวฟ์ ผู้ประกาศในเฮลิคอปเตอร์ตีความผิดซ้ำจนเมืองเข้าใจว่าเธอ "เป็นฝ่ายเชิญ" ราชินีหายไปทำให้สมุนเสียการควบคุม จบสองชั้น: สังคมเกลียด แต่เด็กหนึ่งคนเห็นเธอเป็นฮีโร่
เทคนิค: เปิด-ปิดด้วยชีวิตธรรมดา / ผู้ประกาศหลายชั้น / ผลของตัวร้ายย้อนมา / ภาพลักษณ์กับความจริงไม่ตรงกัน
ไม่ใช้: ฉากกลางตอนที่ใช้ภาพความเป็นเด็กเป็นเนื้อหาทางเพศ (ตัดทั้งหมด) และฉากถูกตรึง

## ตอน 9
ราชินีบาดเจ็บหนีไปหาด็อก แมรี่ในชุดธรรมดาตามไป ทั้งคู่ไม่รู้ตัวตนอีกฝ่าย ต้องปลดปรสิตจากสมุนด้วยวิธีที่ฝั่งพลังทำได้ ต้องร่วมมือ ราชินีเริ่มก่อน แมรี่เปลี่ยนใจเข้าช่วย ผลัดกันนำ แซวกัน เปลี่ยนจากศัตรูเป็นเพื่อนร่วมงาน จบด้วยประกาศว่าจะสู้กันต่อ
เทคนิค: ศัตรูจำใจร่วมมือ / สองชั้นความตลก / ผู้หญิงสองคนในฉาก / ตอนจบประกาศแข่งต่อ (ปรับให้ทุกคนเต็มใจและมีคำหยุด)

## ตอน 10
เธอทำงานร้านนวดกลางคืนใต้ชื่อ "ไมเทอิโกะ" เพื่อเก็บน้ำหลายคน ลูกค้าแรกคือเจ้านายสามีที่จำเธอไม่ได้ มีแต่ความรู้สึกคุ้น ๆ ฉากไต่ระดับ แขน หัวนม จูบ แล้วขั้นต่อไป เธอถามและขออนุญาตทีละขั้น กรอบคำบรรยายสีดำกับตัวนับน้ำ จบด้วยเจ้านายเป็นขาประจำ เธอหมดแรง ข่าวฮีโร่เรียกให้ต้องรีบไป
เทคนิค: ผู้ชายอีกคนมาจากโลกของสามี / ความไม่รู้เป็นแรงตึง / ตัวนับแทนบรรยายยาว / เธอคุมจังหวะ / งานเป็นเหตุผลที่ยอมรับได้
ไม่ใช้: ความคิดของเจ้านายที่ไม่ฟังเสียงเธอ

## ตอน 11 — ไม่ใช้
## ตอน 12
สัตว์ประหลาดยักษ์บุกเมือง แมรี่ใช้ขยายร่างที่เตรียมไว้ แต่ใช้ได้แค่ 3 นาที คุมยาก ถูกจับ เสียงที่สามสามชั้น (ผู้ประกาศ ผู้ชมในเมือง คนดูทีวีที่ทำงาน) ราชินีประกาศ "ยังต้องทดลองต่อ" เมืองรอดอีกวัน
เทคนิค: เวลาจำกัดในตัวพลัง / ข้อแลกเปลี่ยนของพลัง / ผู้ชมหลายชั้น / ศัตรูมีแผน
ไม่ใช้: ฉากหลักที่เธอถูกฝืนใจ และผู้ชมที่ยืนดูเป็นบันเทิง

## ตอน 13
เธอทำร้านนวดต่อใต้ชื่อ "ไมเทอิ วายโกะ" คิวยาวเป็นเดือน แต่พลังไม่เต็ม ด็อกเสนอห้องกิจกรรม VR ให้ขาประจำมาพร้อมกัน เธอถามก่อนทีละคน ห้องเปลี่ยนโลก: เทศกาลฤดูร้อน ยูกาตะ ดอกไม้ไฟ แล้วคาเฟ่เมด แต่ละฉากชุด บรรยากาศ คำเรียก ("ที่รัก" "นายท่าน") ต่างกัน ฝั่งราชินีดูอยู่ จบด้วยลูกค้าหึงที่ต้องแบ่ง และคนใหม่เดินเข้ามา
เทคนิค: ห้องเปลี่ยนโลก / เธอเป็นเจ้าบ้าน ถามและคุมคิว / ชื่อเรียกเปลี่ยนตามฉาก / ลูกค้ามีเรื่องของตัวเอง
ไม่ใช้: ประโยคเปรียบกับเด็ก และฉากลูกค้ารุมแย่งโดยเธอไม่ตกลง

## ตอน 14
ภาคหลังของ 13 ห้อง VR เปลี่ยนเป็นรถไฟแน่น ภาพจำลองสามีโผล่มายืนดู สร้างความรู้สึกผิดและความสับสนว่าเสียวกับความรู้สึกผิดหรือเปล่า สลับกับสามีตัวจริงที่โทรมาจากเกาะ เธอยอมรับกับตัวเองว่าโกหกตัวเองเรื่องหน้าที่ แล้วระบบลบความทรงจำลูกค้าทุกคน
เทคนิค: ฉากสองจอ / ภาพสามีจำลอง / ยอมรับกับตัวเองทีละขั้น / ปุ่มรีเซ็ตตอนจบ
ไม่ใช้: ฉากหลักที่เธอร้อง "อย่า" แล้วถูกทำต่อ

## ตอน 15
แมรี่บินไปอเมริกาใต้ตามหาสามีที่เรือล่ม สามีกับลูกเรือสองคนลอยเคว้ง ดูวิดีโอไมตี้ไวฟ์เป็นความหวัง เขาสงสัยว่าผู้หญิงในคลิปหน้าเหมือนเมีย เธอมาถึงแล้วสามีไม่เชื่อว่าเป็นตัวจริง พลังหมดจึง "ชาร์จ" จากผู้ชายบนเรือ สามีนั่งห่างๆ มองโดยไม่รู้ ฉลามวนรอบเรือ เธอสนุกกว่าที่คิด พลังเต็มแล้วไล่ฉลาม ช่วยทุกคน
เทคนิค: สามีเป็นผู้ชมภรรยาตัวเอง / การรับรู้เปลี่ยนทีละขั้น / ภัยรอบตัวเป็นเส้นตายธรรมชาติ / ปลายตอนเปลี่ยนโทนเป็นแอ็กชัน
ไม่ใช้: ช่วงเปิดที่ถูกจับตรึงและร้องปฏิเสธ (ฉบับใช้งานต้องให้เธอเลือกเอง ลูกเรือถามก่อน)

## ตอน 16 — ไม่ใช้
