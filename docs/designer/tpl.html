ห้องออกแบบสรีระ

ช่องและคำตัวเลือกทุกอย่างตรงกับหมวด "สรีระส่วนตัว" ใน Anima ทุกคำ ทุกตัวเลข และกฎความขัดกันแบบเดียวกัน ปรับแล้วคัดลอกค่าไปใส่ช่องเดียวกันใน Anima ได้เลย ภาพเป็นการ์ตูนพิกเซลแบบง่าย สำหรับผู้ใหญ่เท่านั้น

ระยะในร่างกาย (ค่าเดียวกับช่องใน Anima)

นำเข้าจากตัวละครใน Anima

ใน Anima กดส่งออก (JSON) แล้วเลือกไฟล์ที่นี่ หรือวางข้อความ JSON ลงช่อง ระบบอ่านสีผิว สีผม ขน รูปทรง สี ขนาด และรายละเอียดของตัวละครมาวาดเป็นภาพ ช่องไหนว่างจะเติมด้วยค่าตามสูตรเดียวกับ Anima รับเฉพาะตัวละครหญิงที่อายุ 18 ปีขึ้นไป
